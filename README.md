# Balance — офлайн PWA

Демонстрационный расчёт массы и центровки HS-125-800XP **RA-02734 / SN 258719**, по предоставленной фотографии. Все расчёты и сохранение выполняются на устройстве. Серверная логика, аккаунты и внешние ресурсы не нужны.

## Запуск

На этом Mac достаточно выполнить из папки проекта (скрипт найдёт встроенный Node.js Codex):

```sh
./start.sh
```

При обычной установке Node.js 20 или новее также работает команда ниже. Установка пакетов не требуется:

```sh
npm start
```

Откройте `http://localhost:4173`. Альтернатива: `node scripts/serve.mjs`. Порт задаётся переменной `PORT`. Локальный сервер раздаёт только каталог `dist/`.

Для размещения скопируйте **содержимое `dist/`** на любой статический HTTPS-хостинг. Приложение поддерживает размещение в подкаталоге. `file://` не поддерживает Service Worker.

## Работа

- Первый запуск открывает пример с фотографии. На посадке исходно нет значения: введите общий остаток топлива.
- Переключатель кг/lbs меняет ввод и отображение; сохранённые веса и расчёты остаются в lbs. Ввод допускает десятичную запятую.
- Сначала вырабатывается подфюзеляжный бак, затем крыльевые. Остатки и расход по бакам вычисляются из общего остатка.
- Пустое поле остатка отличается от введённого нуля. Неверные значения блокируют зависимые результаты и печать; превышения ограничений показываются отдельно и печатаются.
- Данные автоматически сохраняются в localStorage текущего браузера. Новый расчёт и восстановление примера заменяют текущий расчёт после подтверждения.
- «Предпросмотр» показывает лист A4. «Печать листа» открывает системный диалог; выберите A4, масштаб 100%, отключите колонтитулы браузера. Можно сохранить PDF. Печать всегда в lbs/ft.
- После появления «Офлайн готов» закройте приложение, отключите сеть и откройте его снова. Форма, графики и печать доступны без сети. На поддерживаемых браузерах появится «Установить»; на iOS используйте Safari → Поделиться → На экран «Домой».
- Профиль браузера и его кеш должны сохраняться: очистка данных сайта удалит расчёт и офлайн-копию.

## Ограничения демо

Не использовать для выполнения полётов. Снаряжённая масса 16 321 lbs, плечо 0,513 ft и плечи загрузочных позиций перенесены из фото; актуальность исходного весового состояния не подтверждена.

Плечи топлива **постоянные: 0,69 ft и 8,36 ft**. В реальном самолёте зависимость может быть иной; кривую из фото показываем только как приближённую справочную иллюстрацию. Максимальный запас крыла 8 446 lbs взят из печатной подписи графика; 7 799 lbs — из рукописного примера. Весовые ограничения: без топлива 18 450 lbs, взлёт 28 000 lbs, посадка 23 350 lbs; багаж 250 / 100 / 45 lbs.

Шкала САХ приблизительная: линейная демонстрационная калибровка относительно точки 0,513 ft / 24,8%, длина условной САХ 6,8 ft. Это **не подтверждённая геометрия самолёта**. Контур центровки приблизительно перерисован по фото; приложение не проверяет эксплуатационный допуск по этому контуру. Печатный бланк повторяет структуру и расположение исходного; это чистая векторная реконструкция фотографии, а не скан оригинального документа.

## Проверки и архитектура

```sh
npm test
npm run check
```

- `dist/src/profiles.js`: модель, борт, места, плечи, ограничения, пример и реестр профилей. Все размеры — lbs/ft.
- `dist/src/calculate.js`: чистые функции расчёта, конвертация, валидация и порядок выработки топлива; JSDoc-типы `AircraftModel`, `AirframeProfile`, `FlightInput`, `CalculationResult`.
- `dist/src/app.js`: интерфейс и состояние; `storage.js`: проверка сохранённого состояния; `graphics.js`: SVG; `print.js`: печатный шаблон.
- `dist/sw.js`: кеш всего приложения. При каждом изменении кешируемых файлов **повышайте версию `CACHE`**; обновление устанавливается только после полного кеширования всех ресурсов.
- `tests/`: контрольные числа фотографии, выработка баков, посадочные итоги, единицы, ограничения, некорректный ввод, сохранение, экранирование и офлайн-оболочка.

Для следующей модели добавьте отдельный `AircraftModel` и `AirframeProfile` в реестр, затем подключите выбор профиля и соответствующую топливную модель. Текущий экран намеренно поддерживает только первый борт; профиль и расчётный модуль уже разделены.
